# QCourts Pickleball — Project Documentation

This folder is the single source of truth for the QCourts Pickleball system:
a marketing website, a court booking backend, and a staff mobile app for
live court/game monitoring. It's written so both a human developer and an
AI coding agent can pick up any part of the project with full context.

1. [`01-project-overview.md`](./01-project-overview.md) — what QCourts is, who it's for, current status
2. [`02-requirements.md`](./02-requirements.md) — functional and non-functional requirements
3. [`03-system-architecture.md`](./03-system-architecture.md) — how the three pieces fit together
